# Roadmap

## 0.3 — Reliability

- Automated tests for product extraction and calculation logic
- CSV export sanitization
- Reduced extension permissions where practical
- Better normalized-title matching
- Explicit source and model version in extension output

## 0.4 — Product intelligence

- Image-assisted product classification
- Structured bill-of-materials editor
- Component-level costs for electronics and furniture
- Packaging dimension and volumetric-freight model
- Region-specific manufacturing scenarios

## 0.5 — Verified evidence

- User-imported supplier RFQs and quotes
- Anonymous calibration against confirmed purchase orders
- Evidence links and comparable-supplier records
- Confidence scoring based on evidence quality

## 1.0 — Hosted platform

- Web dashboard and API
- Saved portfolios and batch analysis
- Authentication and organization workspaces
- Current freight and tariff integrations
- Audit trails and historical model versions
- Export to CSV, Excel, and procurement templates
