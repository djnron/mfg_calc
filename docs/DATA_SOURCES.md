# Data Sources and Provenance

The current catalog uses public sample datasets and merchant-development seed files. It is intended for research and testing, not marketplace replication.

## Amazon

- Public e-commerce sample dataset from Bright Data's dataset-sample repository
- Included records: 1,000
- Typical fields: title, price, currency, category, description, weight, dimensions, and URL
- Limitation: static public sample, not a live or exhaustive Amazon catalog

## Etsy

- Public Etsy sample dataset from Bright Data
- Raw records inspected: 1,000
- Distinct listings included: 20
- Limitation: many source rows represented variants of the same listing

## Shopify

Public Shopify Partner seed CSVs used for development stores:

- Apparel
- Bicycles
- Fashion
- Jewelry / jewellery
- Snow Devil winter-sports catalog

Distinct listings included: 1,623.

These are sample merchant catalogs, not a general crawl of Shopify stores.

## AliExpress

- Public example output from a Bright Data AliExpress scraper repository
- Included records: 5
- Limitation: small sample and incomplete price fields
